# Feature 005: Legacy workshop data parity

This increment replaces the placeholder records on every active modern read
path with the complete normalized synthetic snapshot generated by the legacy
lab.

The snapshot is frozen as of 2018-03-14. It preserves source records and codes
for consultation without authorizing benefit recalculation or inventing
meanings for contradictory legacy statuses.

## Scope

**In scope.** Provenance validation, all six programs, all 500 beneficiaries,
all 2,000 payments, all 200 audit events, reconciliation, atomic activation,
privacy-safe consultation, preservation of legacy codes, and the canonical
Maria demonstration.

**Out of scope.** Recalculation of payments, reinterpretation of unconfirmed
status or type codes, mutation of snapshot records, and modern searches by CPF
or NIS.

## Requirements

**REQ-125** — When the legacy workshop snapshot is generated for the modern
platform, the system shall accept it only when the pinned legacy commit,
generator SHA-256, and normalized content SHA-256 match the approved values.

- `source_legacy:` `github://workshop-gbb/datacorp-sifap-legacy@b87992324dda18bdfc86e6507c3f99b86b99e35d/infra/adabas-natural-lab/provisioning/seed/generate_seed.py#L13-L36`
- **Acceptance.** The approved snapshot is reproducible byte for byte; a
  different commit, generator hash, content hash, schema version, or record
  count fails before a migration is generated or activated.

**REQ-126** — When the approved snapshot is staged, the system shall preserve
exactly 6 programs, 500 beneficiaries, 2,000 payments, 200 audit events, and
the four periods from October 2017 through January 2018.

- `source_legacy:` `github://workshop-gbb/datacorp-sifap-legacy@b87992324dda18bdfc86e6507c3f99b86b99e35d/infra/adabas-natural-lab/provisioning/seed/generate_seed.py#L217-L343`
- **Acceptance.** Every payment resolves to one staged beneficiary and one
  staged period; every beneficiary has exactly four payments; no source row is
  omitted or duplicated.

**REQ-127** — While the approved snapshot is active, the system shall derive
every dashboard, program, beneficiary, payment, report, export, and audit view
from that snapshot instead of the placeholder workshop records.

- `source_legacy:` `github://workshop-gbb/datacorp-sifap-legacy@b87992324dda18bdfc86e6507c3f99b86b99e35d/01-archaeology/legacy-sifap/natural-programs/CONSBENF.NSP#L195-L290`
- **Acceptance.** Placeholder program IDs, placeholder participant names,
  2026 periods, and fabricated activity events are absent from active API and
  user-interface responses.

**REQ-128** — When a viewer searches by name or modern identifier for the
canonical demonstration record, the system shall return `MARIA ALMEIDA
ALMEIDA` as `BEN-000005`, in program `GASF`, located in `CURITIBA`/`PR`, with
four related payments.

- `source_legacy:` `github://workshop-gbb/datacorp-sifap-legacy@b87992324dda18bdfc86e6507c3f99b86b99e35d/infra/adabas-natural-lab/provisioning/seed/generate_seed.py#L200-L314`
- **Acceptance.** Maria's detail shows the same program, location, status,

**REQ-129** — The system shall never expose a complete CPF or NIS in a modern
API response, user interface, URL, application log, trace, error, report, or
export.

- `source_legacy:` `github://workshop-gbb/datacorp-sifap-legacy@b87992324dda18bdfc86e6507c3f99b86b99e35d/01-archaeology/legacy-sifap/natural-programs/CONSBENF.NSP#L199-L205`
- **Acceptance.** Only approved masks and non-sensitive modern identifiers are

**REQ-130** — When the system stores, filters, groups, exports, or displays a
legacy status or payment type, it shall preserve the source code without
silently substituting a modern financial interpretation.

- `source_legacy:` `github://workshop-gbb/datacorp-sifap-legacy@b87992324dda18bdfc86e6507c3f99b86b99e35d/01-archaeology/legacy-sifap/natural-programs/RELPGT.NSP#L161-L194`

**REQ-131** — When the staged snapshot is reconciled, the system shall preserve
every source gross, discount, and net amount exactly, including deliberate

- `source_legacy:` `github://workshop-gbb/datacorp-sifap-legacy@b87992324dda18bdfc86e6507c3f99b86b99e35d/infra/adabas-natural-lab/provisioning/seed/generate_seed.py#L289-L315`

**REQ-132** — When the complete snapshot passes reconciliation, the system

placeholder tables for immediate application rollback.

- `source_legacy:` `github://workshop-gbb/datacorp-sifap-legacy@b87992324dda18bdfc86e6507c3f99b86b99e35d/01-archaeology/legacy-sifap/natural-programs/CCAUDIT.NSC#L51-L60`

  available, and snapshot rows remain append-only.
